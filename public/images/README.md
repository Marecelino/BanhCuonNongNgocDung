# Temporary image placeholders

These SVGs are layout placeholders, not photographs of Bánh Cuốn Nóng Ngọc Dung or its actual dishes. They are intentionally designed as abstract branded artwork so they cannot be mistaken for real shop photography.

## Replacement guide

Replace each placeholder with an owner-approved real photo before production. You can either:
1. Keep the same SVG paths and update `src/data/restaurant.js` to point to the new `.webp` / `.avif` file; or
2. Export/convert the approved photo to a suitable format and preserve the current path only if the content type remains SVG (not recommended).

Recommended real photo slots:
- `hero-food-placeholder.svg`: signature bánh cuốn/bánh ướt plate, landscape, natural morning light.
- `dish-banh-cuon-placeholder.svg`: close-up bánh cuốn / bánh ướt nóng.
- `dish-bun-cha-placeholder.svg`: bún chả Hà Nội serving.
- `dish-bun-moc-placeholder.svg`: bún mọc / sườn non serving.
- `shop-front-placeholder.svg`: actual storefront/signage.
- `preparation-placeholder.svg`: actual preparation process, only if owner approves.
- `brand-mark-placeholder.svg`: replace with official logo artwork when available.

Do not use generated/stock imagery as if it were a real photograph of this shop or its food. For actual food photography, request photos from the owner.
